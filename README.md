# Révisions Marcus

Appli de révision installable (PWA) pour la classe de seconde : fiches PDF, flashcards à répétition espacée, quiz, fiches animées et vidéos, rangés par matière.

- Contenus : `catalogue.json` et dossier `contenus/`.
- Progression : locale, synchronisée entre appareils avec le code famille (Supabase).
- Installation : ouvrir l'adresse dans Safari, Partager > Sur l'écran d'accueil.
